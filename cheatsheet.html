Our robot

1 wheel turn= 17.5 cm = 360° Quarter turn≈ 11 cm of wheel travel (or use a gyro turn) Wheelsports C + D Fork armport E · 90° from down to all the way up Color sensorfront right corner, looking down (port F in the simulator: check yours) Sizeabout 19 × 16 cm

Driving

  • move ↑ forward for 20 cm drive a set distance
  • set movement speed to 50 % slower is more exact
  • start moving … stop moving drive until something happens
  • move steering -30 for 20 cm curve; minus is left, plus is right
  • gyro turn ↻ right by 90 degrees the most exact way to turn (a ready-made My Block in Glow Bot Lab; in the SPIKE app, make your own or use move ↻ spin right for 11 cm)
  • set yaw angle to 0 first block of every program

The fork arm

  • E run ↺ for 90 degrees lift
  • E run ↻ for 90 degrees lower
  • Don't keep pushing once it hits the mat or the top. That strains the motor.
  • After setting something down, back away with the fork still down, then lift.

Sensors and waiting

  • wait 1 seconds
  • wait until color is black ? pause until it's true
  • reflected light 0 = black, 100 = white
  • yaw angle how far the robot has turned
  • timer seconds since start (or since reset timer)
  • C relative position how far a wheel turned. Didn't change? You're stuck!

Loops and decisions

  • repeat 4 do it a set number of times
  • repeat until keep going until something is true, then move on
  • forever never ends! Blocks under it never run
  • if … then … else choose what to do
  • and or not < = > build a question

Variables (counters)

  • Variables menu → Make a Variable, e.g. lines
  • set lines to 0 at the start
  • change lines by 1 each time something happens
  • lines = 4 inside repeat until or if
  • write lines show it on the hub screen to check

My Blocks (functions)

Write the hard part once, then use it again and again.

  • My Blocks → Make a Block, name it (“follow line”)
  • Add an input (“seconds”) so each use can be different
  • Put the steps under define follow line
  • Use it: follow line 5.5

Two things at once

  • Each when … block starts its own stack, and they all run together
  • when color is red starts when the sensor sees red
  • broadcast done → when I receive done lets stacks talk to each other
  • broadcast done and wait waits until that stack finishes
  • stop other stacks ends the others (great for a forever loop)
  • stop and exit program ends everything. Use it last

Find home
repeat until color is white or timer > 15
set C relative position to 0 move back 4 cm
if C relative position barely changed: go around (forward 8, left 90, 30 cm, right 90, back 40, left 90, back 30, right 90)
then move back 6 cm more: the sensor is at the front

Match Day

  • Same start every time: back against the wall, line up on a mark, hands off, then press start.
  • Push slowly: 25 % speed or less when pushing a model.
  • Get home: drive the route backward, aim for the middle of the launch area, then back up a little extra.
  • Fully home (robot and everything it's touching) = free pickup.
  • Grabbing it outside home costs a precision token:

When it doesn't work

  • Run it slowly and watch where it first goes wrong.
  • Change one number at a time.
  • Check the ports and that the battery is charged.
  • Stuck in a forever loop? Use a second stack or repeat until.
  • Works once but not always? Fix the start before the program.
